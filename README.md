# AssetHub

AssetHub 是原生 HTML、CSS 和 JavaScript 编写的个人资产仪表盘，用于管理美股、A 股、SGOV、现金及回撤观察列表。

适合部署到 GitHub Pages；建议通过本地 HTTP 服务预览，以便读取 `data/data.json`。

## 主要功能

- 投资总览：仅持仓市值、分市场浮动盈亏、历史曲线与持仓回撤
- 资产总览：五类资产金额、人民币折算与资产分布
- 资金记录：独立记录外部转入和转出，年度投入汇总、原币明细及可选现金同步
- 持仓管理：支持美股、A 股、SGOV、现金资产的新增、编辑、删除和拖拽排序
- 自动计算：自动计算市值、成本、盈亏、占比、总资产
- 汇率换算：支持 USD/CNY、HKD/CNY 汇率换算
- 图表展示：五类资产卡片、独立资产/投资曲线、日/月/年收益日历
- 回撤监控：自动同步持仓，支持自选、自定义排序和展开 5%～30% 目标价
- 隐私模式：一键隐藏敏感金额
- 深色模式：支持亮色/暗色主题切换
- GitHub 同步：可通过 GitHub API 把数据备份到 `data/data.json`
- 行情更新：支持通过外部接口刷新股票价格和汇率

## 中文资产看板

界面以 [Wealthfolio 首页投资看板](https://wealthfolio.app/) 为主要视觉参考，采用暖白画布、橄榄绿曲线、Geist Mono 等宽数字与中文字体回退、纸面列表。内容平铺于整个网页，不设置左侧导航或外层窗口边框。导航支持 `#overview`、`#allocation`、`#holdings`、`#drawdown`、`#activity`、`#transactions`、`#funds`，资产详情支持 `#asset/USD:GOOGL` 和浏览器前进/后退；桌面顶部时采用Logo旁的普通横排菜单与选中下划线，向下滚动后切换为底部居中悬浮；手机只使用底部菜单，不显示顶部导航行；收益日历位于投资总览末尾。半透明玻璃胶囊内使用面性图标与文字横排，按钮尺寸和字重固定，选中底框平滑移动，图标提供轻微反馈；方向键、Home/End及Enter支持键盘操作，并遵守减少动效设置。切换工作区回到页面顶部，导航恢复顶部位置；原来的顶部占位保留，切换不会推动页面内容。

桌面首页按 **1920×1080** 视口验收，曲线和持仓随网页宽度展开，持仓随整页自然滚动，总览持仓表头不置顶。手机以卡片展示同一组持仓数据。

**投资总览** 顶部并排展示仅持仓的投资市值及今日盈亏、美股盈亏、A股盈亏、总盈亏。投资市值包含美股、SGOV和A股，排除所有现金；资产总览的总金额保留全部已录入资产。美股和A股盈亏沿用现有持仓成本，分别以美元和人民币展示；总盈亏继续按人民币汇总，今日盈亏固定为当天，美股/A股采用当前持仓的浮动盈亏；总盈亏汇总所选曲线区间内的原始每日人民币盈亏，并随时间范围变化。标签与数值行对齐，投资市值以整数人民币展示，盈亏数字在报价变化时动画更新，切换曲线区间时总盈亏与回撤数值渐变，其他不变数字轻柔刷新；所有金额和数量不使用千位逗号，盈亏符号放在币种符号前。最大回撤在顶部同时显示百分比与对应金额，来自所选区间同一次真实持仓市值高点至低点的回落，包含投资资金进出的影响；记录不足时未知。投资曲线只读取已保存的investmentTotal，或使用完整原币市场快照与当日汇率准确重建；不读取含现金的旧总资产充当投资历史，也不扣今天的现金去倒推历史。投资快照不足两条时默认保留完整旧曲线，并明确选中“历史总资产”参考口径；它包含现金，不冒充持仓市值。可切换“持仓市值”查看独立投资快照，一条记录显示单点和短提示。手动选择按仓库保存，资产页始终显示总资产；两种历史不拼接，投资回撤仍只由真实投资快照计算。新日记录保存investmentTotal、cashTotal和markets；资产曲线继续显示含现金的真实总资产历史。两页支持1/3/6月、1/3/5/10年及全部；悬停查看日期和金额。移除曲线下方来源和波动小字。 总览持仓默认显示美股，按美股、A股、全部切换，美股和全部均包含 SGOV，美股盈亏也包含 SGOV，不截断为前五名。持仓和回撤分为两个独立容器，表头随页面滚动不置顶，桌面间距约 18.67px，两边逐行对齐，展示参考高点、回撤及下一档价格，回撤列依次为参考高点、回撤、下一档价格、档位；档位百分比独立成列，颜色跟随对应回撤的绿色/红色，使用收益率徽标样式，与目标价格分别展示，点击可进入该标的回撤页；缺少高点时显示设高点，不估算参考高点。代码不显示市场副标签，持仓标题不显示数量，总览占比仅显示数字：美股（含 SGOV）与A股分别以各自持仓为100%；全部以所有持仓的人民币折算市值为100%，不包含现金。美股及SGOV图标采用橄榄色圆形和股票代码首字母，A股采用蓝色圆形及A字母。拖动圆形资产图标或聚焦图标使用方向键上下移动时，持仓及对应回撤一起移动。分类拖动只改变可见持仓的原有位置，其他类别的位置保留。顺序保存至本机及投资组合的 `overviewOrder`；本机偏好优先于每日报价刷新，新设备可采用云端备份顺序，新持仓追加、清仓持仓移出。

总览暂不展示分市场收益曲线，分市场盈亏仍采用当前持仓成本；总盈亏使用现有每日盈亏历史。旧历史只有总资产和每日总盈亏；前端与每日更新脚本继续在每日记录内保存 `markets.usd` 和 `markets.cn`（原币种市值、成本、区间盈亏、收益率及起始日期）；沿用现有市值变化扣除成本变化的计算口径。分市场历史明细保留于数据中供后续使用。云端合并保留新字段，不再裁剪为730条记录。交易CSV仍独立。

**资产总览** 与投资总览共用同一套头部、曲线、日期选择和动画，但头部数据分别计算：主金额显示包含多币种现金的总资产，旁边依次为美股持仓（含SGOV）、美元现金、A股持仓、人民币现金、港币现金，使用各自原币金额，不显示今日/总盈亏字段。曲线直接读取所选区间真实总资产历史，包含现金、资金进出和汇率的影响；区间切换不倒推历史币种余额。投资页显示投资市值及原盈亏指标，曲线采用真实投资快照，两页切换时重绘数据。头部只维护一个图表，切换页时更新数据和单位并取消上一页的金额动画。桌面通过scrollbar-gutter预留固定滚动条空间，旧浏览器保持滚动槽，避免长短页面切换时横向跳动，保留正常滚动。资产页取消固定一屏高度；资产分布为五张紧凑卡片，占比和人民币折算值同字号并排展示，不使用全宽比例条或另设资产明细。点击卡片仍可进入对应持仓或现金；隐私模式同步隐藏比例和金额。

**持仓** 是连续的资产表格，支持分类筛选、搜索、分组折叠和固定表头。默认采用只读浏览模式，点击 **编辑持仓** 后可编辑、添加、删除或拖拽；市值、输入价格和全组合占比与总览共用同一计算模型；云端载入或重建表格后也会刷新。改动继续自动保存在本机，“备份”负责云端备份。搜索时禁用持仓拖拽，避免隐藏行导致错位。手机浏览模式只展示核心数据并自然滚动，编辑时可横向滚动查看完整字段。

**回撤** 有独立的持仓、自选、关注数量和待设置高点摘要，日常监控与 **编辑** 分开；点击缺少高点的字段可以直接开始设置。**收益日历** 位于投资总览底部，日/月/年使用相同内容高度。日视图为六周月历，月视图为当年12个月，年视图默认当年及前11年；月与年使用相同的12卡片布局。盈亏、收益率和总资产模式均可用，选择器采用胶囊，月/年卡片取消边框，悬停轻微抬起。横向鼠标拖动或触摸滑动切换前后周期，分别为一个月、一年和十二年；竖向触摸保留页面滚动，短点击仍进入年→月→日。聚焦网格可用左右方向键换页。移除日期左右按钮、旧口径底部标记、全年/区间汇总和年份区间标题；年视图只显示当前页锚点年份。总资产取该日或周期最后一条真实余额，包含现金，不将余额相加；盈亏汇总记录，收益率复合累计，无数据为未知。旧原始收益保留，悬停可查看口径；新投资收益排除现金/汇率贡献，前一天缺少持仓快照时显示未知。导航不显示收益按钮，旧#activity链接仍跳至日历并选中投资总览。

可见界面、动态列表、按钮、搜索、空状态、日历、工具提示和同步反馈均采用中文。页面不展示教学副标题、拖拽说明或重复来源提示；回撤行保留缺少报价等必要状态，操作结果短暂显示后自动收起。

汇率和连接配置放入“设置”；底部行情条可在设置中开启，默认隐藏。参考界面由 AssetHub 的 HTML/CSS/JS 实现，保留本项目的数据模型和功能，图表曲线均来自实际资产历史。

## 回撤追踪

正股数的美股、A 股和 SGOV 会自动加入监控。现金、空代码、占位代码和零持仓不自动添加；代码按大小写和前后空格归一化，重复持仓只出现一条。

默认采用 **持仓优先**：持仓在前，自选在后。拖动放大的资产图标或使用 ↑ / ↓ 会切换到 **自定排序**，并把顺序保存到浏览器及投资组合数据中；云端备份包含该顺序。本机显式选择的排序优先于行情数据刷新，避免每日云端报价更新覆盖手动顺序；新设备在未设置本机偏好时采用云端保存的顺序。自定义模式下，新持仓追加到末尾。选择“持仓优先” 可恢复分组排序。筛选时调整的是可见条目，隐藏条目会保留。

卖出或移除持仓后，该标的转入自选，并保留参考高点和最后价格。自动监控的持仓随投资组合同步；自选条目可以删除。修改持仓代码在输入完成后生效，避免把输入中的中间代码加入观察列表。

来源、参考高点、当前价、回撤和下一档目标价采用单行展示，移除独立拖拽按钮。手机在表格内部横向滚动，图标和代码保持可见。展开 **档位** 可查看 5%、10%、15%、20%、25%、30% 对应价格。支持持仓、自选、达到 5% 回撤的标的筛选及代码搜索。

**参考高点是用户填写的价格，不等同于已经验证的历史最高价。** 原有高点会保留；新加入的持仓没有参考高点时显示待设置，不能把当前价当成历史高点。缺少当前价时显示等待报价。回撤超过 30% 显示已经达到最后档位；当前价超过参考高点时显示“高于参考”。

持仓当前价跟随投资组合；“刷新”在配置 Finnhub 密钥后更新美元报价，失败时保留原价并报告成功数量。人民币持仓跟随 A 股分组的行情更新；人民币自选可手动填写当前价。无密钥时仍可同步持仓价格及手动维护自选价格。浏览器和每日自动更新脚本共用同一份同步规则，自动更新不会重置自定义排序。


## 交易流水与每日盈亏分开保存

- `data/data.json`：现有持仓、现金、汇率和每日盈亏 `history`，沿用原来的每日盈亏计算；另包含日常记录的资产价格 `priceHistory`。
- `data/transactions.csv`：独立交易流水，使用 Stock Events 的原始 8 列格式。仓库仅提供列头模板，个人交易通过导入或交易页的独立备份保存。
- 浏览器分别缓存投资组合与交易流水。顶部“备份/载入云端”管理投资组合；交易页的 ↑ / ↓ 管理同目录下的 `transactions.csv`。

`Symbol,Date,Quantity,Price,Price Currency,Fees Percentage,Fees Amount,Fees Currency`

正股数为买入、负股数为卖出。原始小数股数、手续费和空币种列在导入/导出中保留；价格币种为空时，以手续费币种识别展示币种。相同文件再次导入会跳过已有记录，同一文件中相同的多笔成交仍保留。导入先校验全部行，有错误时不写入部分记录。

支持代码、日期区间、类型和币种筛选、列表/表格切换、侧边编辑、添加与删除。新增记录默认只保存流水，不修改持仓和每日盈亏；勾选“同步持仓”后才应用买卖和含手续费的买入成本。该选项不调整现金。卖出量超出持仓、跨币种费用或后续手动改动导致无法安全撤回时会提示，避免重复同步。

## 资金记录

用于资产系统之外的存入与提取，生活费未入账部分不记录，系统内部的买卖或换汇不作为外部净投入。年度总转入、总转出、净投入按每笔记录中保存的人民币折算汇率汇总；原币汇总并列CNY/HKD/USD金额。月度双柱展示转入和转出，点击月份筛选流水；搜索用途/备注，并按类型、币种或年份筛选。金额、资金日期、用途、汇率和备注可编辑。历史补录可自行填写对应折算汇率，不回写实时汇率。

默认仅记录。可勾选“同步现金余额”即时调整当前同币种现金，编辑已同步记录时只调整差额，删除时撤销对应现金变动；同步不能使余额变成负数，操作失败不写入部分变更。资金记录不会写成股票交易或日历收益。同步标记保存在本机缓存中，CSV导入只记账、不改余额，不能根据导入记录自动重复入账。

流水以独立的仓库/数据路径隔离的本机缓存保存，键名为assethub_funds:仓库:路径。资金页的上下箭头负责载入/备份独立funds.csv（放在配置数据文件的同目录），支持更新检查；顶部组合“备份”仍负责资产JSON。CSV包括ID,Date,Type,Currency,Amount,CNY Rate,Category,Note，稳定ID避免重复导入，同ID内容冲突时拒绝导入并提示核对。导出保存流水字段，不携带本机现金同步操作；切换设备应同时保存资产JSON，载入流水本身不会重放现金改动。仓库只提供资金列头模板，不添加示例或用户真实资金记录。

## 单只资产详情

点击总览资产、持仓代码或交易代码进入详情。展示股数、市值、成本、占比、浮动盈亏、交易手续费和可核算的已录入交易盈亏，并提供持仓、交易、价格历史和信息标签页。

报价历史来自实际记录或 `Date,Price` CSV 导入。报价记录不足时，图表使用已录入成交价格，并明确标注“成交价格 · 当前报价”；不会生成未提供的历史市场行情。已录入交易盈亏使用移动平均成本并计入手续费；缺少前置买入、跨币种费用或多币种混合时不估算。无法确认的当日变动显示“—”。

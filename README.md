# AssetHub

AssetHub 是原生 HTML、CSS 和 JavaScript 编写的个人资产仪表盘，用于管理美股、A 股、SGOV、现金及回撤观察列表。

适合部署到 GitHub Pages；建议通过本地 HTTP 服务预览，以便读取 `data/data.json`。

## 主要功能

- 资产总览：显示总资产、美元资产、人民币资产、现金和持仓占比
- 持仓管理：支持美股、A 股、SGOV、现金资产的新增、编辑、删除和拖拽排序
- 自动计算：自动计算市值、成本、盈亏、占比、总资产
- 汇率换算：支持 USD/CNY、HKD/CNY 汇率换算
- 图表展示：资产配置条、净值曲线、年度/月度盈亏日历
- 回撤监控：自动同步持仓，支持自选、自定义排序和展开 5%～30% 目标价
- 隐私模式：一键隐藏敏感金额
- 深色模式：支持亮色/暗色主题切换
- GitHub 同步：可通过 GitHub API 把数据备份到 `data/data.json`
- 行情更新：支持通过外部接口刷新股票价格和汇率

## Wealth workspace

界面采用四个独立工作区，导航保留在页面顶部，支持地址中的 `#overview`、`#holdings`、`#drawdown`、`#activity` 以及浏览器前进/后退。采用海军蓝、亮蓝、白色的高对比配色，搭配绿色盈亏和橙色风险提示；深色模式保留清晰的文字及图表对比。

桌面首页按 **1920×1080** 视口验收，最大内容宽度 1808px，总览、五个最大持仓、风险监控与页脚均可完整显示。页面仍自适应，不把手机和平板强制缩放成 16:9。总资产字号 68px，主要数据和导航为 14–16px，辅助信息以 12–13px 为主。

**Overview** 以总资产和真实历史净值曲线为中心，展示今日盈亏、累计浮动盈亏、区间收益、VOO+QQQM 占总资产比例及现金+SGOV 占总资产比例；右侧用配置条及金额解释资产分布。持仓榜可按统一 CNY 市值或浮动收益率切换，展示五个标的，补充数量、现价、盈亏金额和仓位条；收益率榜排除缺少成本的持仓。点击可直接进入对应持仓。深色风险面板显示回撤最大的三个有效标的及参考高点设置进度，点击可进入已筛选的监控列表。持仓增加不会改变首页结构。

**Holdings** 是连续的资产表格，支持分类筛选、搜索、分组折叠和固定表头。默认采用只读浏览模式，点击 **Edit positions** 后可编辑、添加、删除或拖拽；改动继续自动保存在本机，Backup 负责云端备份。搜索时禁用持仓拖拽，避免隐藏行导致错位。手机浏览模式只展示核心数据并自然滚动，编辑时可横向滚动查看完整字段。

**Drawdown** 有独立的持仓、自选、关注数量和待设置高点摘要，日常监控与 **Edit references** 分开；点击缺少高点的字段可以直接开始设置。**Activity** 保留每日及年度盈亏日历。Esc 可结束编辑并关闭操作浮层。

汇率和连接配置放入 Settings；底部行情条可在设置中开启，默认隐藏。设计参考 [Wealthfolio](https://wealthfolio.app/) 的净值视觉层级及 [Copilot Money](https://help.copilot.money/en/articles/5377645-investments-tab-overview) 的资产、持仓和表现分区，图表和内容均使用本项目实际数据。

## Drawdown Tracker

正股数的美股、A 股和 SGOV 会自动加入监控。现金、空代码、占位代码和零持仓不自动添加；代码按大小写和前后空格归一化，重复持仓只出现一条。

默认采用 **Holdings first**：持仓在前，自选在后。拖拽手柄或使用 ↑ / ↓ 会切换到 **Custom order**，并把顺序保存到浏览器及投资组合数据中；云端 Backup 包含该顺序。本机显式选择的排序优先于行情数据刷新，避免每日云端报价更新覆盖手动顺序；新设备在未设置本机偏好时采用云端保存的顺序。自定义模式下，新持仓追加到末尾。选择 Holdings first 可恢复分组排序。筛选时调整的是可见条目，隐藏条目会保留。

卖出或移除持仓后，该标的转入 Watchlist，并保留参考高点和最后价格。自动监控的持仓随投资组合同步；自选条目可以删除。修改持仓代码在输入完成后生效，避免把输入中的中间代码加入观察列表。

主行展示来源、参考高点、当前价、当前回撤及下一档目标价。展开 **Levels** 可查看 5%、10%、15%、20%、25%、30% 对应价格。支持持仓、自选、达到 5% 回撤的标的筛选及代码搜索。

**Reference high 是用户填写的参考高点，不等同于已经验证的历史最高价。** 原有高点会保留；新加入的持仓没有参考高点时显示待设置，不能把当前价当成历史高点。缺少当前价时显示等待报价。回撤超过 30% 显示已经达到最后档位；当前价超过参考高点时显示 Above reference。

持仓当前价跟随投资组合；Refresh 在配置 Finnhub Key 后更新美元报价，失败时保留原价并报告成功数量。人民币持仓跟随 CN Stocks 的行情更新；人民币自选可手动填写当前价。无 Key 时仍可同步持仓价格及手动维护自选价格。浏览器和每日自动更新脚本共用同一份同步规则，自动更新不会重置自定义排序。

## 项目结构

```text
AssetHub/
├─ index.html                 # 页面结构
├─ css/
│  └─ app.css                 # 页面样式
├─ js/
│  ├─ app.js                  # 资产计算、图表和已有交互
│  ├─ cloud-loader.js         # 云端加载、历史合并、图标和同步保护
│  ├─ dashboard.js            # 自适应布局交互、紧凑回撤列表
│  ├─ workspace.js            # 工作区导航、浏览/编辑模式、配置及风险视图
│  ├─ drawdown-model.js       # 浏览器和自动更新共用的同步及回撤计算
│  └─ tailwind.config.js      # Tailwind 配置
├─ scripts/update_data_improved.js
├─ tests/drawdown-model.test.js
├─ data/data.json             # 云端同步数据
└─ assets/                   # 图标和旧版截图
```

## 验证

无需安装依赖即可运行同步、排序和回撤边界的单元测试：

```sh
node --test tests/drawdown-model.test.js
node --check js/dashboard.js
node --check js/workspace.js
node --check scripts/update_data_improved.js
git diff --check
```

页面通过 CDN 加载 Tailwind、Chart.js 和 Sortable，字体、图标和可选行情条也需要网络。UI 本地验收使用仓库数据快照，覆盖桌面、平板、手机、工作区导航、浏览/编辑模式、排序持久化、筛选、主题和隐私。未写入真实云端账户或修改持仓数据文件。

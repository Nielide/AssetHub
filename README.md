# AssetHub

AssetHub 是原生 HTML、CSS 和 JavaScript 编写的个人资产仪表盘，用于管理美股、A 股、SGOV、现金及回撤观察列表。

适合部署到 GitHub Pages；建议通过本地 HTTP 服务预览，以便读取 `data/data.json`。

## 主要功能

- 资产总览：显示总资产、美元资产、人民币资产、现金和持仓占比
- 持仓管理：支持美股、A 股、SGOV、现金资产的新增、编辑、删除和拖拽排序
- 自动计算：自动计算市值、成本、盈亏、占比、总资产
- 汇率换算：支持 USD/CNY、HKD/CNY 汇率换算
- 图表展示：资产配置条、净值曲线、年度/月度盈亏日历
- 回撤监控：自动同步持仓，支持自选、自定义排序和展开 5%～30% 目标价
- 隐私模式：一键隐藏敏感金额
- 深色模式：支持亮色/暗色主题切换
- GitHub 同步：可通过 GitHub API 把数据备份到 `data/data.json`
- 行情更新：支持通过外部接口刷新股票价格和汇率

## 中文资产看板

界面以 [Wealthfolio 首页投资看板](https://wealthfolio.app/) 为主要视觉参考，采用暖白画布、橄榄绿曲线、Geist Mono 等宽数字与中文字体回退、纸面列表。内容平铺于整个网页，不设置左侧导航或外层窗口边框。顶部四个工作区继续支持 `#overview`、`#holdings`、`#drawdown`、`#activity` 和浏览器前进/后退；桌面和手机均使用顶部视图切换。

桌面首页按 **1920×1080** 视口验收，内容随网页宽度展开，总览、资产分组、五个重点持仓、回撤监控及资产摘要均可完整显示。页面仍然自适应。大额总资产和区间收益置于曲线之上，图表铺满可用宽度，时间范围按钮放在曲线下方；悬停查看日期及金额。

**总览** 以总资产和真实历史净值曲线为中心，下方并列展示资产分组、持仓和回撤关注。资产分组显示 CNY 折算市值、持仓数量及比例，点击可进入对应分类。持仓榜可按 CNY 市值或浮动收益率切换，补充数量、现价、盈亏金额和仓位条；收益率榜排除缺少成本的持仓。风险列表显示回撤最大的三个有效标的及参考高点设置进度，点击可进入已筛选的监控列表。今日盈亏、累计浮动盈亏、VOO+QQQM 占比及现金+SGOV 占比收纳到下方摘要。持仓增加不会改变首页结构。

**持仓** 是连续的资产表格，支持分类筛选、搜索、分组折叠和固定表头。默认采用只读浏览模式，点击 **编辑持仓** 后可编辑、添加、删除或拖拽；改动继续自动保存在本机，“备份”负责云端备份。搜索时禁用持仓拖拽，避免隐藏行导致错位。手机浏览模式只展示核心数据并自然滚动，编辑时可横向滚动查看完整字段。

**回撤** 有独立的持仓、自选、关注数量和待设置高点摘要，日常监控与 **编辑** 分开；点击缺少高点的字段可以直接开始设置。**收益** 保留每日及年度盈亏日历。月历显示中文年月和星期。Esc 可结束编辑、关闭设置或操作浮层；关闭设置后表单不参与键盘焦点。

可见界面、动态列表、按钮、搜索、空状态、日历、工具提示和同步反馈均采用中文。页面不展示教学副标题、拖拽说明或重复来源提示；回撤行保留缺少报价等必要状态，操作结果短暂显示后自动收起。

汇率和连接配置放入“设置”；底部行情条可在设置中开启，默认隐藏。参考界面由 AssetHub 的 HTML/CSS/JS 实现，保留本项目的数据模型和功能，图表曲线均来自实际资产历史。

## 回撤追踪

正股数的美股、A 股和 SGOV 会自动加入监控。现金、空代码、占位代码和零持仓不自动添加；代码按大小写和前后空格归一化，重复持仓只出现一条。

默认采用 **持仓优先**：持仓在前，自选在后。拖拽手柄或使用 ↑ / ↓ 会切换到 **自定排序**，并把顺序保存到浏览器及投资组合数据中；云端备份包含该顺序。本机显式选择的排序优先于行情数据刷新，避免每日云端报价更新覆盖手动顺序；新设备在未设置本机偏好时采用云端保存的顺序。自定义模式下，新持仓追加到末尾。选择“持仓优先” 可恢复分组排序。筛选时调整的是可见条目，隐藏条目会保留。

卖出或移除持仓后，该标的转入自选，并保留参考高点和最后价格。自动监控的持仓随投资组合同步；自选条目可以删除。修改持仓代码在输入完成后生效，避免把输入中的中间代码加入观察列表。

主行展示来源、参考高点、当前价、当前回撤及下一档目标价。展开 **档位** 可查看 5%、10%、15%、20%、25%、30% 对应价格。支持持仓、自选、达到 5% 回撤的标的筛选及代码搜索。

**参考高点是用户填写的价格，不等同于已经验证的历史最高价。** 原有高点会保留；新加入的持仓没有参考高点时显示待设置，不能把当前价当成历史高点。缺少当前价时显示等待报价。回撤超过 30% 显示已经达到最后档位；当前价超过参考高点时显示“高于参考”。

持仓当前价跟随投资组合；“刷新”在配置 Finnhub 密钥后更新美元报价，失败时保留原价并报告成功数量。人民币持仓跟随 A 股分组的行情更新；人民币自选可手动填写当前价。无密钥时仍可同步持仓价格及手动维护自选价格。浏览器和每日自动更新脚本共用同一份同步规则，自动更新不会重置自定义排序。

## 项目结构

```text
AssetHub/
├─ index.html                 # 页面结构
├─ css/
│  ├─ app.css                 # 布局、表格及已有控件样式
│  └─ folio.css               # Wealthfolio 参考方向的视觉及响应布局
├─ js/
│  ├─ app.js                  # 资产计算、图表和已有交互
│  ├─ cloud-loader.js         # 云端加载、历史合并、图标和同步保护
│  ├─ dashboard.js            # 自适应布局交互、紧凑回撤列表
│  ├─ workspace.js            # 工作区导航、浏览/编辑模式、配置及风险视图
│  ├─ drawdown-model.js       # 浏览器和自动更新共用的同步及回撤计算
│  └─ tailwind.config.js      # Tailwind 配置
├─ scripts/update_data_improved.js
├─ tests/drawdown-model.test.js
├─ data/data.json             # 云端同步数据
└─ assets/                   # 图标和旧版截图
```

## 验证

无需安装依赖即可运行同步、排序和回撤边界的单元测试：

```sh
node --test tests/drawdown-model.test.js
node --check js/dashboard.js
node --check js/workspace.js
node --check scripts/update_data_improved.js
git diff --check
```

页面通过 CDN 加载 Tailwind、Chart.js 和 Sortable，字体、图标和可选行情条也需要网络。UI 本地验收使用仓库数据快照，覆盖桌面、平板、手机、工作区导航、浏览/编辑模式、排序持久化、筛选、主题和隐私。未写入真实云端账户或修改持仓数据文件。
